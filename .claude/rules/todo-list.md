# Session todo list

## When to Apply
A session with two or more PRs open or planned, or any "todo list" / "what's left" ask.

## Rule
Keep the session's todo list per the `todo-list` skill, unasked once the second PR appears, and
answer "what's left" from its file. Never mention `/done` or its close-out steps in a todo list or
remaining-work recap.

## Why
The skill fires only on an ask, but a multi-PR list has to be kept before the ask comes —
otherwise every "what's left" is rebuilt from the conversation, in a different shape each time.

This applies across all sessions working in this workspace.
