# Rules stay minimal

## When to Apply
When writing or editing a file in `.claude/rules/`.

## The Rule

Every rule is loaded into every session, so every line is paid for in every context window,
forever. Write the shortest prose that changes behavior: the trigger, the rule, one sentence of
why. Target **under 30 lines** — past that, justify each extra line or cut it.

The usual excess:

- a table or ✅/❌ pair restating bullets that already said it
- a worked example longer than a sentence
- a Why section re-arguing a point the rule already made
- the rule restated in different words further down

Say it once. If a second paragraph exists to clarify the first, the first was wrong — fix it
rather than add to it.

Existing over-long rules are not a cleanup backlog; don't sweep them. This governs what gets
written next.

This applies across all sessions working in this workspace.
